# Hướng dẫn deploy demo 48h — Railway (PromotionPilot AI)

## 1. Chuẩn bị GitHub
- Commit & push toàn bộ thay đổi (kể cả data/pharmacity_demo.csv ~40MB).
- File cấu hình: Procfile, railway.toml, runtime.txt, .streamlit/config.toml

## 2. Tạo service trên Railway
1. https://railway.app → New Project → Deploy from GitHub repo.
2. Chọn repo promotionAI1.
3. Settings → Resources: chọn máy **ít nhất 8 GB RAM / 4 vCPU** (khuyến nghị 16 GB nếu 40+ người cùng forecast).
4. Tắt sleep / idle (nếu plan có) — tránh cold start lúc thuyết trình.

## 3. Biến môi trường (Variables)
```
DEMO_ACCESS_CODE=
DEMO_MAX_HEAVY_JOBS=10
DEMO_MAX_UPLOAD_MB=30
LLM_ENABLED=false
```
Đổi mã PROMO2026 thành mã riêng của buổi demo. Phát mã cho người tham dự.

## 4. Start command (đã có trong Procfile / railway.toml)
```
streamlit run app.py --server.port=$PORT --server.address=0.0.0.0 --browser.gatherUsageStats=false --server.headless=true
```

## 5. Sau khi có URL công khai
1. Mở URL → nhập mã → Data → **Dùng dữ liệu mẫu**.
2. Chạy Forecast 1 lần + Simulate 1 lần (warmup).
3. Phát URL + mã cho 30–50 người; nhắc: chỉ dùng dữ liệu mẫu, tránh cùng lúc bấm «Phân tích giỏ hàng».

## 6. Plan B khi nghẽn
- Presenter demo trên màn hình chính.
- Tạm dừng dùng thử tự do / nâng RAM lên 16 GB trên Railway.
